zenjpegai: JPEG AI (ISO/IEC 6048) decoded in the browser

A pure-Rust, #![forbid(unsafe_code)] port of the JPEG AI reference software, compiled to WebAssembly and run in Web Workers. Every image below is decoded client-side — nothing is pre-rendered. Source: github.com/imazen/zenjpegai.

Model weights:

Where a decode's time goes: headers, integer entropy decode, hyper-scale decoder and latent reconstruction always run on the CPU (bit-exact/integer stages; multi-threaded on the threads packages). Synthesis, output conversion and presentation run on the GPU when the WebGPU path is taken, else on the CPU; post-filters a stream signals run on the CPU after synthesis (these demo streams are tools-off).
